# Зельеварение (Potions)

Стартовые ингредиенты (12 штук — все, что нельзя получить комбинациями): Бутылочка воды, Адский нарост, Сахар, Паучий глаз, Кроличья лапка, Огненный порошок, Слеза гаста, Золотая морковь, Черепаший панцирь, Мембрана фантома, Порох, Дыхание дракона.

## Рецепты

Бутылочка воды + Адский нарост = Неловкое зелье  
Неловкое зелье + Сахар = Зелье стремительности  
Зелье стремительности + Сахар = Зелье стремительности (дл.)  
Зелье стремительности + Адский нарост = Зелье стремительности II  
Неловкое зелье + Кроличья лапка = Зелье прыгучести  
Неловкое зелье + Огненный порошок = Зелье силы  
Неловкое зелье + Слеза гаста = Зелье регенерации  
Неловкое зелье + Золотая морковь = Зелье ночного зрения  
Зелье ночного зрения + Приготовленный паучий глаз = Зелье невидимости  
Бутылочка воды + Приготовленный паучий глаз = Зелье слабости  
Неловкое зелье + Паучий глаз = Зелье отравления  
Неловкое зелье + Черепаший панцирь = Зелье черепашьей мощи  
Неловкое зелье + Мембрана фантома = Зелье плавного падения  

### Дополнительные ингредиенты

Паучий глаз + Сахар = Приготовленный паучий глаз  
Бутылочка воды + Паучий глаз = Зелье отравления  

### Взрывные и туманные зелья

Зелье стремительности + Порох = Зелье урона  
Зелье отравления + Порох = Зелье урона  
Зелье урона + Дыхание дракона = Туманное зелье  
Зелье слабости + Порох = Зелье урона  

### Улучшения

Зелье регенерации + Сахар = Зелье регенерации
